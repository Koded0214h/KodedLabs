# Koded Labs — Landing Page Build Spec

A GitHub-inspired dark landing page for Koded Labs (independent product studio). Restrained, technical, proof-driven — not a generic dark-mode SaaS page. Every visual element earns its place by showing real work, not decorating.

---

## 0. Design Principles

- **Layered dark, not flat dark.** Depth through elevation (surface shades), not shadows.
- **One accent family:** blue → purple gradient, used sparingly (Products section, Pre-footer CTA, focus states). Everything else stays monochrome.
- **3D as spot illustration, not wallpaper.** Each 3D moment uses a distinct model, contained and purposeful, never sprawled across a viewport.
- **Motion is functional.** Reveal-on-scroll, hover feedback, one deliberate hero animation. No idle looping "because we can."
- **Reused components, not reinvented per section.** Browser-chrome frame, card grammar, stat count-up, and ticker/marquee are each built once and reused.
- **Real proof over claims.** Screenshots, real recordings, real numbers — text describes, media proves.

---

## 1. Design Tokens

**Color**
```
--bg-base:      #0a0a0a
--bg-hero:      #0d0d0d
--bg-surface:   #111111   /* section shift, one level up from base */
--bg-card:      #141414
--border:       #232323   /* hairline, 1px */
--text-primary: #f5f5f5
--text-secondary: #8b8b8b
--accent-blue:  [lock exact hex when picked]
--accent-purple:[lock exact hex when picked]
--status-live:  #39d353   /* green, live/status dots only */
```

**Typography**
- Headings: clean humanist sans (not mono)
- Body: same sans family, lighter weight
- Labels / meta / stats / stack tags / footer legal: monospace
- Mono reserved strictly for labels and numerals — never body copy

**Spacing / radius**
- Consistent card radius across all card-style components (Products, video frame, browser-chrome, input)
- Section vertical rhythm consistent top-to-bottom (lock a spacing scale: e.g. 96px/120px section padding desktop, 64px mobile)

**Shared components to build once, reuse everywhere**
- `BrowserChromeFrame` — used for hero video, Products screenshots
- `Card` — used for Products (bordered, hover-lift) — explicitly NOT reused for Education (grid tiles, no border/lift)
- `StatCounter` — count-up on scroll-into-view, used in Trust bar (and optionally Education if a stat is added there)
- `Marquee/Ticker` — slow horizontal drift, used in Trust bar (program names) and How We Build (language strip)
- `GlowGradient` — radial, blurred, accent-colored — used in Hero, Products, Pre-footer CTA only (bookends the accent color across the page)
- `SectionHeading` — centered variant (Products, Education, Pre-footer CTA) vs left-aligned variant (How We Build)

## 3. Hero

```
┌──────────────────────────────────────────────────────────────┐
│              We build products that solve                     │
│              real problems.                                    │
│         Independent product studio · Lagos, NG                │
│         [ View Products ]   [ Read the story ]                │
│                    ╱ ─ ─ glow ─ ─ ╲                            │
│              ┌───────────────────────┐                         │
│              │ ▸ [ product demo video ]│  browser-chrome frame │
│              └───────────────────────┘                         │
└──────────────────────────────────────────────────────────────┘
```
- Mascot (primary 3D model, largest instance alongside Pre-footer CTA) does ONE deliberate idle animation on load — not constant rotation.
- Headline: clean sans, center or left per final layout call — locked as centered mission statement with subtext below.
- **Scroll cue = glow + demo video**, not an arrow:
  - `GlowGradient` positioned at top edge of the video frame, centered, blurred (`filter: blur(40-60px)`), accent color at ~15-20% opacity, subtle pulse loop (opacity 0.15→0.25, 3-4s ease-in-out).
  - Video frame: `BrowserChromeFrame`, muted autoplay/loop of best product demo (Ship or Scafld — confirm which). Clicking jumps to Products section or opens full-size.
  - `prefers-reduced-motion`: freeze glow pulse, use poster image instead of autoplay.
- Respect `prefers-reduced-motion` globally for all 3D/motion; pause render loops on `visibilitychange`; cap `dpr` at `[1, 1.5]`.

## 5. Products Showcase

```
┌──────────────────────────────────────────────────────────────┐
│                  [ 3D model #2, centered ]                     │
│                     small, one idle anim                       │
│                    SECTION HEADLINE (TBD)                      │
│         Subtext — one sentence, narrow max-width, centered      │
│                 ╱ ─ blue/purple glow ─ ╲                       │
│  ┌───────────────────────┐  ┌───────────────────────┐        │
│  │ ● LIVE           01   │  │ ● LIVE           02   │        │
│  │  [ screenshot ]        │  │  [ screenshot ]        │        │
│  │  NAME                  │  │  NAME                  │        │
│  │  One-line description  │  │  One-line description  │        │
│  │  Tech · Tags           │  │  Tech · Tags           │        │
│  │  url.kodedlabs.com  ↗  │  │  url.kodedlabs.com  ↗  │        │
│  └───────────────────────┘  └───────────────────────┘        │
└──────────────────────────────────────────────────────────────┘
```
- Centered layout: 3D model → headline → subtext → glow → 2-col card grid.
- 3D model is a **different asset** than the hero mascot — distinct per-section identity.
- `GlowGradient` (blue→purple) sits behind/beneath the text block — this is the page's primary accent-color moment; confirm this gradient IS the locked accent going forward (reused in Pre-footer CTA).
- Cards: simple 2-col (1-col mobile), `BrowserChromeFrame` screenshot, name, one-line description, mono tech tags, live URL, `StatusDot` if genuinely live vs. muted "IN PROGRESS" label.
- Data-driven from `data.js` — array of products, card grid maps over it. Adding a product = data change only.
- Fade/slide-up on scroll, staggered ~80ms per card. Hover: border tint toward accent + `translateY(-4px)`, ~150ms ease-out, no 3D tilt (calmer than mascot-scale moments).

**`data.js` shape (products):**
```js
{
  id: "ship",
  name: "Ship",
  order: "01",
  status: "live" | "in_progress",
  description: "One-line, plain language.",
  stack: ["Rust", "Postgres"],
  url: "https://ship.kodedlabs.com",
  screenshot: "/assets/products/ship.png"
}
```

## 6. How We Build

```
┌──────────────────────────────────────────────────────────────┐
│  HOW WE BUILD                                                  │
│  ┌───────────────────┐        ┌─────────────────────────┐   │
│  │ Systems first,      │        │ [ screen recording,       │   │
│  │ not UI first.       │        │   muted, click-to-play ]  │   │
│  │                     │        │                    ⊙▶     │   │
│  │ Short narrative      │        │        (play btn, gray    │   │
│  │ paragraph.           │        │      rounded bg, bottom-  │   │
│  └───────────────────────┘        │      right, ~16-20px pad)│   │
│                                     └─────────────────────────┘   │
├──────────────────────────────────────────────────────────────┤
│   RUST   GO   PYTHON   TYPESCRIPT   POSTGRES   SOLANA   ···    │
└──────────────────────────────────────────────────────────────┘
```
- Asymmetric editorial split — left-aligned headline, ~40/60 or 45/55 text/video split desktop, stacks on mobile (text first, then video).
- **No live terminal animation in this section** (explicitly cut).
- Video: real poster still (not generic placeholder), does NOT autoplay. Play button overlay: circle, translucent gray/dark bg (`rgba(255,255,255,0.1)` + blur), small triangle icon, bottom-right of frame. Click plays inline in place.
- `data.js` should support a `video` field per instance if multiple clips will ever be swapped in — don't hardcode a single clip path in the component.
- Language/tool strip beneath: reuse `Marquee` component, mono, uppercase, low opacity (~40-50%), slow drift.
- Fade/slide-in on scroll, no stagger needed (only two blocks).

- 3D model here is the **largest on the page** alongside (or exceeding) the hero mascot — closing "full circle" statement.
- Centered headline + subtext, same narrow max-width pattern as Products/Education.

- Input styling matches card/frame aesthetic: dark fill, thin border, focus state = accent-colored `box-shadow` glow, not a harsh outline.
- Reuse `GlowGradient` (blue/purple) one final time, subtly behind the model or input — bookends the accent across the page.
